# 台灣辦公日曆（預交日用）

- `tw_2026.csv`（115 年）、`tw_2027.csv`（116 年）：原檔內容未修改。
- 來源：政府資料開放平台 https://data.gov.tw/dataset/14718 「中華民國政府行政機關辦公日曆表」，行政院人事行政總處。
- 欄位：`西元日期,星期,是否放假,備註`；是否放假 0 = 上班（含補班）、2 = 放假。UTF-8（含 BOM）。
- 更新（不用重新 build）：把 `tw_YYYY.csv` 放到資料目錄的 `holidays/`（容器內 `/app/data/holidays/`），優先於本目錄；
  或執行 `python -m app.tools.update_tw_holidays [--year 2028]` 自動下載。
- 沒有該年資料時，只把週末與固定國定假日（1/1、2/28、4/4、4/5、5/1、9/28、10/10、10/25、12/25）當假日（備援）。
